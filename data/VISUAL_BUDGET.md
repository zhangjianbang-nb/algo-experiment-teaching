# 视觉下限（L2 交付档，开工先照这张表）

字数只证明"写了多少"，公式/表/图才证明"讲没讲清"。`verify_site.py --phase all`
的 `check_visuals()` 逐单元判，缺一项就 FAIL。

| 单元 | 公式 | 表 | 图 |
|---|---:|---:|---:|
| 每篇论文 | ≥1 个 `$$...$$` | ≥1 张实验/对照表 | ≥2 张（流水线 + 证据链；有 prereq 时一张换家谱） |
| 每个算法 | ≥1 个 | ≥1 张速查表 | ≥1 张执行流程图 |
| 每张理论卡 | ≥1 个 | ≥1 张对照表 | ≥1 张先修关系图 |
| 每个方向 | — | ≥1 张关键论文表 | ≥1 张问题→技术→论文图 |
| 每个故事 | — | roles/mapping 表 | ≥1 张故事地图 |
| 全书每章 | ≥1 个 | ≥1 张表 | 全书合计 ≥6 张 |
| 附录 | — | ≥3 张索引表 | ≥1 张结构图 |
| 题库合计 | ≥100 个 | ≥100 张 | — |
| **全站** | — | — | **≥80 张** |

## 三条判定口径

1. **公式只认 KaTeX 可渲染的 `$$...$$`**。裸 LaTeX（没有定界符）和 Unicode 符号
   （θ / Σ / − / ∼ / ⇒ / ⟨⟩）不算；先转成 `\theta` / `\sum` / `-` / `\sim` /
   `\Rightarrow` / `\langle`，再包 `$$`。`<div class="formula">` 里的伪代码不算公式。
2. **图只认「内联 `<svg>` + `<figcaption>` ≥8 可见字」**。`<img>`、外链图、AI 生成图不算；
   图注必须写数据来源（"依据 papers.json 的 pipeline 字段绘制，非论文原图"）。
3. **表只认带 `<thead>` 或 `<th>` 的 `<table>`**。纯 `<div>` 网格不算表。

## 反填充

- 图必须回答一个具体问题（数据怎么流 / 谁先谁后 / 差在哪），不能是装饰色块。
- 同一张图不许复制到多个页面充数；图里的数字必须能在 JSON 里查到。
- `prereq` 为空时不要硬编家谱；用 `pipeline` + `problem→core_idea→results` 两张图，
  图注写明"家谱数据未录入，本图展示方法链"。
- 补图脚本要幂等：用 `<!--VIS:key:start-->…<!--VIS:key:end-->` 包住，重跑先删旧块。

参考实盘：MOPD 站 36 论文 ×2 + 60 算法 + 58 理论 + 8 方向 + 5 故事 + 6 书章 + 1 附录
= 210 张图；补完 `verify_site --phase all` 从 333 个视觉错误降到 0。
